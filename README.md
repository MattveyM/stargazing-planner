# Stargazing Planner

A full-stack web app that finds the best night and place to stargaze in the Pacific Northwest.

**Tech:** React, Leaflet, Python FastAPI, PostgreSQL

## Run locally (Mac)

Front end: `cd frontend` → `npm install` → `npm run dev`
Back end: `cd backend` → `source venv/bin/activate` → `pip3 install -r requirements.txt` → `uvicorn main:app --reload`
